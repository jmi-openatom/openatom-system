# 校园模型实现与参考范围

模型使用用户提供的校园手绘总图、鸟瞰效果图和沙盘照片；这些是整体形态参考，并非立面测绘资料。校园楼名、ID、位置、边界、高度字段仍来自 `campusBuildings.json`。其中参考图补绘的轮廓和现有高度本来就是估算，不能视为测量值。

## 当前还原内容

- 图书馆：环形阅览体块、分层窗带、中央采光顶、沿现有北侧弧形轮廓的斜玻璃屋面、屋面分格与低层附属翼。
- 体育馆：沿原椭圆范围建立低层外墙、环形玻璃带、浅拱屋盖、外围立柱与径向屋面接缝。
- 海涵楼：保留原位置和最高高度，区分低层裙房、北侧主楼及竖向玻璃体块。
- 躬行楼、笃行楼、景行楼：按鸟瞰图补充三翼内院和浅灰坡顶，原用于定位的 GeoJSON 不变。
- 教学楼、宿舍：沿已有实际轮廓生成墙体，补充窗格、楼层腰线、阳台、浅色屋顶平台、蓝色屋面带和白色屋顶框架。宿舍六层窗格是鸟瞰参考中的视觉估算。
- 游泳馆：主泳池、小池、浅色池岸、北侧配套楼、西侧低层遮阳棚与泳道线，池面保持露天。
- 澄园宿舍：按补充卫星图纠正 2、3 号及 6、7 号位置名称；1、2、4、7 号保留南北高层主体，连接段降为低层，屋顶改用照片中的灰褐色。
- 沁园北区：1、2、3 号按最新轮廓图改为西侧连接、东侧开口的 C 形院落；4 号开口朝西，5 号保留折角形。使用全校卫星截图的体育馆、图书馆与田径场控制点进行局部配准，并对北区进行校界约束修正；全部北区补绘建筑完整轮廓在校内，坐标仍属于参考估算。
- 创客中心：按用户确认补在念稼食堂北侧独立小楼位置，加入楼名、目录与模型选择；轮廓、高度及位置标记为估算。
- 灯塔及小山：保留用户指定位置，山脚改为平滑椭圆网格，并与 DEM 的地面高度衔接。

当前资料看不到的侧立面、窗格尺寸、入口和材质属于保守补全；不能宣称逐栋达到实景照片或测绘级还原。将来有近景照片时应逐栋替换轮廓和立面配置，避免把估计值当作事实。

海艺楼南侧轮廓按用户补充的卫星参考图收缩，保留与敬德楼之间至少 10 米的地面间隔；调整记录在 `outline_source` 中。这处间隔尚不是实测尺寸。

校内道路保留原有 61 条 OSM 数据，按参考图补足北区及校园连接路的缺失段，使用校园边界与建筑轮廓裁切。主路、次路与步道分别配置宽度，复用两条 Mapbox 原生线图层。截图控制点、像素轮廓和道路追踪记录见 `scripts/campus-reference-alignment.json`。

## Mapbox 接入

`campusLandmark.ts` 在原有 Mapbox custom layer 中同时渲染建筑、山体和灯塔，复用地图 WebGL context。`campusArchitecture.ts` 返回以米为单位的轻量模型；通过 WGS84 → Mercator 的变换正确定位，不增加 Threebox 或其他地图框架。

- 原生 Mapbox 保留 DEM terrain、hillshade、道路、水体、植被、标签和远景建筑。
- 缩放小于 15.2 时使用原生挤出体块；15.2 起显示自定义建筑，16.1 起显示窗格、阳台等近景细节。
- 原挤出图层在近景中透明，避免深度缓冲遮住新模型。模型点击与 hover 使用渲染矩阵反投影进行射线拾取，并返回原始建筑 ID；楼名图层保留原点击入口。
- 模型地面高度随 DEM 到达而更新，基础向地下延伸 2.5 米，用于覆盖区域 DEM 与水平楼板之间的小误差。
- 窗片采用两三角面，按材质合并；整套 41 栋模型约 19.8 万三角形、13.6 MiB 顶点数据，远景主体约 126 个 mesh。近景细节可被视锥剔除。
- 自定义阴影使用固定 2048 阴影贴图，仅在 DEM 高度改变时重建；不运行永久重绘循环。
- Mapbox 与自定义模型共享光照颜色和方向。夜景仅点亮部分窗格。

## 验证

在 `frontend/web_pc` 执行 `pnpm check:campus-models`，检查建筑 ID 完整性、顶点有效性、模型高度与标签的关系、绘制/三角形预算和选择材质恢复。`pnpm build` 验证生产打包。地图组件另做定向 Vue/TypeScript 检查；根 tsconfig 的空 files 配置不能代替全量应用类型检查。

图书馆日景已经做过浏览器近景检查。后续卫星图修正之后的实际浏览器仍需要检查日夜切换、模型点击、搜索定位、楼名显示、缩放、旋转和空间键平移，不能只凭打包通过判断场景正常。
