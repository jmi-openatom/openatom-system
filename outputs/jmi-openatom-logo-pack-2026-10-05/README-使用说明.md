# JMI-OPENATOM Logo 素材包

名称：开放原子开源社团<br>
英文：JMI-OPENATOM<br>
制作日期：2026-10-05

根据提供的蓝色齿轮、协作节点与海浪图案转绘，保留主体轮廓和比例，统一为干净的纯色矢量图形。中文为主、英文为辅。

## 内容

共 **20 个成品 SVG、60 个 PNG**，另附 3 个可编辑文字 SVG、图形矢量源文件、原始参考图和总览图。

| 文件夹 | 排版 | PNG 尺寸 |
| --- | --- | --- |
| `01-square-symbol` | 正方形纯图标 | 512×512、1024×1024、2048×2048 |
| `02-square-bilingual` | 正方形中英文字版 | 512×512、1024×1024、2048×2048 |
| `03-horizontal-bilingual` | 横向长方形中英文字版，3:1 | 1200×400、2400×800、4800×1600 |
| `04-vertical-bilingual` | 竖向长方形中英文字版，3:4 | 600×800、1200×1600、2400×3200 |

每个排版文件夹均有 `png` 和 `svg` 两个子文件夹。

## 配色名称

| 文件名关键词 | 含义 | 用法 |
| --- | --- | --- |
| `blue-transparent` | 蓝色图标＋深蓝中文＋蓝色英文，透明底 | 浅色网页、PPT、文档 |
| `blue-white` | 上述蓝色组合，白色底 | 直接发送、发布或预览 |
| `white-transparent` | 全白图形与文字，透明底 | 放在深色背景上 |
| `white-navy` | 全白图形与文字，深蓝底 | 深色页面、展示图 |
| `black-transparent` | 全黑图形与文字，透明底 | 单色印刷、盖印等 |

白色透明底文件在纯白预览器中看起来为空白，请放到深色背景上查看。

## 推荐使用

- 头像、应用图标：`01-square-symbol` → `blue-transparent` → 1024×1024 PNG。
- 社交主页、封面上的方形标识：`02-square-bilingual` → `blue-transparent` → 2048×2048 PNG。
- 网页导航、横幅、文档页眉：`03-horizontal-bilingual` → `blue-transparent` → SVG 或 2400×800 PNG。
- 海报、竖版物料：`04-vertical-bilingual` → SVG 或 2400×3200 PNG。
- 放大、印刷或设计软件导入：优先使用成品 SVG。

## SVG 与文字源文件

成品 `svg` 文件夹中的图形与文字均为真实矢量路径，没有内嵌 PNG、外链图片、外部字体或脚本依赖，可以独立使用和任意缩放。

`source` 中的三个 `editable-text.svg` 保留可编辑文字，便于后续更改名称。中文使用 PingFang SC Semibold，英文使用 Avenir Next Demi Bold；如需保持源文件中的文字外观，需在编辑电脑上具备相应字体。成品 SVG 已转曲，不需要这些字体。

`source/mark-traced.svg` 是从参考图轮廓转绘的图形矢量源文件；`source/original-reference.png` 是用户提供的原图。原图中轻微的色彩波动已统一为纯色，主体没有重新设计。

## 颜色

- 主色蓝：`#0085FC`
- 中文文字深蓝：`#10365B`
- 深色底：`#0D1B2A`

PNG 均按其标示的像素尺寸直接从矢量文件导出，包含 300 DPI 元数据；实际清晰度以像素尺寸为准。素材采用 RGB/sRGB，若用于专业印刷，可在排版软件中按印厂要求转换颜色。

`preview-overview.png` 为四种排版和配色示意。`manifest.json` 列出成品文件、像素尺寸、透明状态与校验值。
